# 🌰 수상한 도토리 마을

> 친구들과 함께하는 실시간 웹 마피아 게임

**수상한 도토리 마을**은 귀여운 동물 캐릭터로 마을을 돌아다니며 시민과 마피아가 서로의 정체를 추리하는 **실시간 멀티플레이 소셜 디덕션 게임**입니다. 시민은 미션을 수행하고 마피아를 찾아내야 하며, 마피아는 시민을 방해하고 정체를 숨기며 승리를 노립니다.

[🎮 **게임 플레이하기**](https://dotori-village-game.onrender.com/) · [💻 **GitHub 저장소**](https://github.com/KongJJoki/dotori-village-game)

## 🎲 게임 소개

- **플레이 인원:** 3~12명
- **진행 방식:** 닉네임 및 캐릭터 선택 → 방 생성 / 코드로 입장 → 준비 → 게임 시작
- **역할 배정:** 게임 시작 시 시민과 마피아를 무작위로 배정
- **승리 조건**
  - **시민:** 모든 시민 미션 완료 또는 마피아 전원 추방
  - **마피아:** 살아 있는 마피아 수가 살아 있는 시민 수 이상

| 전체 인원 | 마피아 |
| --- | ---: |
| 3~6명 | 1명 |
| 7~10명 | 2명 |
| 11~12명 | 3명 |

## ✨ 주요 기능

### 🏡 실시간 멀티플레이
- **Socket.IO** 기반으로 플레이어 이동, 상태, 채팅 및 게임 이벤트를 동기화
- 방 코드로 친구들과 같은 게임에 참여
- 게임 시작 전 **대기실 채팅** 및 준비 상태 확인
- 한 판이 끝나면 **같은 방에서 다시하기** 지원

### 🐰 시민과 😈 마피아
- 시민은 마을 곳곳에서 **순서 맞추기 미니게임**으로 미션 진행
- 마피아는 가짜 미션으로 위장하고 시민을 습격
- 게임마다 역할을 재배정하며, 직전 판과 **완전히 동일한 마피아 조합의 연속 배정 방지**

### 📣 긴급회의 및 투표
- 시체 신고 또는 긴급회의로 토론 시작
- **토론 시간, 투표 남은 시간, 투표 완료 인원, 후보별 득표수** 표시
- 자신이 선택한 후보의 투표 완료 상태 확인
- 생존자가 모두 동의하면 토론을 끝내고 **바로 투표** 가능

### ⚡ 정전 사보타지
- 마피아가 정전을 일으켜 시야를 제한
- 시민은 발전기 근처에서 **배선 순서 맞추기 미니게임**을 완료해 복구에 참여
- 방 인원에 따라 필요한 수리 성공 인원 변경
  - 3~4명: 1명
  - 5~8명: 2명
  - 9~12명: 3명

### 🕳️ 벤트 이동
- 마피아 전용 비밀 이동 통로
- 야외, 빵집, 창고, 풍차의 벤트 지점 사이 이동
- 하수구 덮개 그래픽과 **열림·닫힘 및 이동 연출** 적용

## 🕹️ 조작 방법

| 조작 | 기능 |
| --- | --- |
| `W` `A` `S` `D` / 방향키 | 이동 |
| `E` | 문 출입, 미션 및 발전기 상호작용 |
| `F` | 습격 (마피아) |
| `R` | 시체 신고 |
| `V` | 벤트 사용 (마피아) |
| `Enter` | 게임 중 채팅 입력 |

화면의 버튼으로도 주요 동작을 실행할 수 있습니다.

## 🛠️ 기술 스택

| 구분 | 기술 |
| --- | --- |
| Frontend | HTML, CSS, JavaScript, Canvas API |
| Backend | Node.js, HTTP Server |
| 실시간 통신 | Socket.IO |
| 배포 | Render |
| 버전 관리 | Git, GitHub |

프레임워크 없이 Canvas로 마을과 캐릭터를 렌더링하고, 서버에서 역할·이동·미션·투표·승패 등의 게임 상태를 관리합니다.

## 🚀 로컬 실행

**필요 환경:** Node.js 18 이상, npm

```bash
git clone https://github.com/KongJJoki/dotori-village-game.git
cd dotori-village-game
npm install
npm start
```

터미널에 서버 실행 메시지가 나타나면 브라우저에서 **http://localhost:3000** 에 접속합니다.

친구와 온라인으로 플레이하려면 배포된 [게임 링크](https://dotori-village-game.onrender.com/)를 이용하세요.
